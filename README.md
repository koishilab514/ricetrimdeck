# 라이스트림덱 (RiceTrimDeck)

메이플스토리 창 바로 아래에 붙어 다니는 버튼 패널이에요.
스트림덱처럼 자주 쓰는 프로그램·사이트·음악·소리 조절을 마우스로 바로 눌러요.

## 받기

**[최신 버전 받기](https://github.com/koishilab514/ricetrimdeck/releases/latest)** 에서 `RiceTrimDeck-버전.zip` 을 받아 압축을 풀고 `라이스트림덱.exe` 를 실행하면 돼요. 설치는 필요 없어요.

- 윈도우 10 / 11 (64비트)
- 처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 눌러 주세요. 서명하지 않은 개인 프로그램이라 뜨는 창이에요.

## 할 수 있는 것

- **열기**: 프로그램·폴더·설치된 앱·웹 주소 버튼. 바탕화면의 바로가기나 브라우저 주소를 빈 칸에 끌어다 놓아도 돼요.
- **음악**: 이전 곡·재생·다음 곡, 패널 아래 미디어 줄(곡명·볼륨)
- **소리**: 출력 장치·프로그램별 볼륨 창, 출력 장치 바로 바꾸기, 프로그램 소리 끄기, 마이크 끄기
- **녹화**: 메이플 게임 화면만 녹화, 메이플 소리만 녹음 (그래픽카드로 압축해서 게임이 덜 버벅여요)
- **정보**: 시계·날짜, CPU·GPU·RAM 사용량, 메이플 프레임(FPS)
- **꾸미기**: 버튼 그림을 PNG·움직이는 GIF 로 바꾸기, 그림만 보이는 장식 칸

## 알아 두세요

- 메이플에 키를 대신 눌러 주는 기능은 없어요. 게임 파일이나 게임 안을 건드리지 않아요.
- 창 모드나 테두리 없는 전체화면에서 패널이 보여요.
- 녹화에는 무료 도구 ffmpeg 가 필요해요. 설정 > 녹화 > "ffmpeg 받기"를 누르면 공식 배포처에서 받아 와요.
- 메이플 프레임 재기는 윈도우의 화면 기록을 읽어서, 켤 때 관리자 허락 창이 떠요.
- 끄기: 작업 표시줄 오른쪽 아래 트레이 아이콘(청자색 네모 4개) 오른쪽 클릭 → 종료
- 1.0.7 부터는 새 버전이 나오면 알림이 뜨고, 버튼 한 번으로 업데이트돼요. 1.0.6 이하를 쓰고 있다면 이번 한 번만 직접 받아 주세요.
- 자세한 쓰는 법은 zip 안의 `사용법.txt` 에 있어요.

### 1.0.17 (11월 24일)

- 몬컬 보상 알림 버튼을 넣었어요(오른쪽 클릭 > 시계·정보). 보상을 받고 누르면 다음에 받을 시각이 나오고, 그 시각이 되면 보물 상자에 빨간 점이 떠요. 간격은 1·3·6·24시간 중에 골라요. PC를 꺼도 기록은 남아요.
- 캐릭터 펫이 더 자연스럽게 움직여요. 걷기를 멈추거나 돌아설 때 몸이 옆으로 순간이동하던 것을 고쳤고, 멈춘 뒤에도 마지막으로 걸은 쪽을 봐요. 걷다가 가끔 멈춰 쉬고, 칸 끝에서는 잠깐 섰다가 돌아서요.
- 주간 보스를 다 잡아 깡총 뛸 때도 반짝이는 표정을 그대로 유지해요.
- 펫이 가만히 서 있는 시간을 줄이고 걷기·공격·엎드리기 같은 동작을 더 자주 해요.
- 캐릭터 버튼 하나에 캐릭터를 최대 6명까지 넣을 수 있어요. 편집 창 캐릭터 목록에서 누르면 넣고, 다시 누르면 빼요. 각자 따로 돌아다니고, 마주쳐도 게임에서처럼 그냥 겹쳐서 지나가요.
- 여러 명을 넣은 버튼을 누르면 남은 보스 창에서 ◀ ▶(또는 휠·←→)로 캐릭터를 넘겨 봐요. 창 크기는 한 명일 때와 같아요.
- 캐릭터 칸 크기를 가로 1\~10칸 × 세로 1\~3줄 중에서 자유롭게 고를 수 있어요. 지금 쓰는 2×2·4×2 칸은 그대로예요.
- 남은 보스 숫자는 이제 기본으로 꺼져 있어요. 편집 창에서 켜면 보이고, 여러 명이면 각 캐릭터 머리 위에 나와요.
- 편집 창에 "캐릭터 크기" 막대를 넣었어요. 펫 크기를 40\~100% 사이에서 5% 단위로 고를 수 있어요(기본 80%).
- 편집 창의 "캐릭터가 오른쪽 보기" 설정을 없앴어요. 바라보는 쪽은 걷는 방향이 정해요.
- 캐릭터마다 크기가 달라 보이던 것을 고쳤어요. 이제 모두 같은 비율로 그리고, 발바닥을 같은 바닥에 맞춰요(긴 무기를 든 캐릭터가 작아지거나 떠 보이지 않아요).

### 1.0.16 (11월 23일)

- 최신 ffmpeg(9.1)를 받으면 녹화가 시작되지 않던 문제를 고쳤어요. 옛 ffmpeg 도 그대로 써요.
- 프로그램 아이콘(청자색 네모 4개)이 오른쪽 아래로 1칸 치우쳐 있던 것을 가운데로 맞추고, 테두리를 또렷하게 했어요.
- 녹화 중에 메이플 프레임을 켜서 관리자 허락 창이 뜨면, 그때부터 영상이 멈추고 소리만 녹음되던 문제를 고쳤어요. 이제 허락 창·잠금 화면이 떠 있는 동안은 "잠깐 멈춤"이 나오고, 화면이 돌아오면 이어서 녹화해 한 파일로 저장해요.
- 영역 지정 녹화를 소리 없이 할 수 있어요 (설정 > 녹화 > 소리 > "영역 지정 녹화는 소리 없이").
- 페이지·숨기기 칸에 마우스를 올렸다 옮기면 말풍선이 마우스 자리에 늦게 뜨거나 남아 있던 문제를 고쳤어요. 이제 칸 바로 위에 뜨고, 벗어나면 바로 사라져요.
- 버튼 이름을 숨겼을 때 자동 종료·타이머 칸도 쉬는 동안은 이름을 숨기고 아이콘·시간을 크게 보여 줘요. 돌아가는 중에는 끝나는 시각이 그대로 나와요.

### 1.0.15 (11월 23일)

- 동영상 칸을 넣었어요. 내 PC 의 영상 파일 하나·여러 개·폴더를 넣으면 칸(기본 가로 3칸 × 세로 2줄)에서 계속 재생해요. 처음에는 소리가 꺼져 있고, 휠을 굴리면 이 칸 소리만 바뀌어요. 누르면 멈추거나 다시 재생하고, 다음·이전 영상은 오른쪽 클릭 메뉴에 있어요. 미디어 줄과 미디어 키에는 나오지 않고, 패널 진하기를 낮춰도 영상은 선명해요. 패널을 숨기거나 다른 페이지로 가면 멈춰요.
- 타이머 알림음 크기를 버튼마다 고를 수 있어요 (100%·75%·50%·25%·10%).
- 버튼 이름을 숨기고 아이콘만 크게 보이게 할 수 있어요 (설정 > 패널 > 버튼 이름). 기본은 3줄에서만 숨기고, 마우스를 올리면 이름이 나와요.
- 이름표 스티커(이름 뒤 둥근 바탕)를 켜고 끌 수 있어요 (설정 > 패널). 자동 종료·타이머 칸 이름에도 스티커가 똑같이 나오게 고쳤고, "볼륨 40" 같은 알림 글자는 칸이 좁으면 글자를 줄여 다 보여 줘요.
- 동영상 칸을 가로 5칸 × 세로 3줄로도 키울 수 있어요 (3줄 패널용). 3줄 패널에서 새로 넣으면 처음부터 5×3 이에요.
- 타이머 시간에서 초 칸에 60 이상을 넣으면 분으로 바꿔 줘요 (100초 → 1분 40초).
- 세로 줄 수를 1줄·2줄·3줄 중에서 고를 수 있어요 (설정 > 패널). 1줄에서는 세로 2줄 버튼을 쓸 수 없어서 '못 써요' 칸으로 보여 주고, 지우지는 않아요. 3줄은 버튼 크기 기본이 가장 작은 크기이고, 직접 조절로 바꿀 수 있어요(3줄 크기는 따로 기억해요). 페이지 상자는 패널 높이에 맞춰 저절로 2열로 접혀요.

### 1.0.14 (11월 23일)

- 모니터 밝기 버튼을 넣었어요. 버튼 위에서 휠을 굴리면 5%씩, 누르면 30% → 60% → 100% 순서로 바뀌어요. 모든 모니터를 한꺼번에 바꾸거나 모니터 하나만 고를 수 있어요. 외장 모니터는 모니터 메뉴에서 DDC/CI 가 켜져 있어야 해요.
- 캘린더 버튼을 넣었어요. 누르면 날짜별로 메모를 쓰는 달력 창이 열리고, 오늘 메모가 있으면 버튼 그림에 빨간 점이 붙어요. 달력 창 위쪽 "배경"에서 그림을 넣을 수 있어요.

### 1.0.13 (11월 22일)

- 패널을 끌어서 옮길 때 화면 가장자리 가까이 가면 딱 붙어요. 모서리에서는 두 변에 같이 붙고, 작업 표시줄은 피해요. 조금 더 끌면 떨어져요. 설정 > 일반 > 자리에서 끌 수 있어요.
- 버튼 편집 창에서 휠로 창을 내리다 펼침 상자(크기·소리 등)나 숫자 칸 위를 지나가면 값이 바뀌던 문제를 고쳤어요. 이제 눌러서 고를 때만 바뀌어요.

### 1.0.12 (11월 21일)

- 패널 한 줄처럼 납작하고 긴 영역을 녹화하면 시작하자마자 "녹화가 멈췄어요"가 뜨던 문제를 고쳤어요. 1080p·1440p로 키울 때 가로가 너무 커지지 않게 맞춰요.
- 녹화·캡처의 "창 고르기"에서 라이스트림덱 패널도 고를 수 있어요. 패널을 소개하는 영상·스샷을 찍을 때 써요. 패널을 골라 녹화하면 설정대로 라이스트림덱 소리만 들어가요(타이머 알림음 등). 다른 소리까지 넣으려면 설정 > 녹화 > 소리에서 "스피커로 나가는 모든 소리"를 고르면 돼요.
- 설정 > 정보의 문의에 "카카오톡 오픈채팅으로 문의하기" 버튼이 생겼어요.
- 창 고르기에서 창이 없는 곳(바탕 화면 등)을 눌러도 바로 닫히지 않고 다시 고를 수 있어요.

### 1.0.11 (11월 21일)

- 라이스트림덱 폴더를 통째로 다른 곳에 옮겨도 패널 배경 그림·캐릭터 배경이 그대로 나와요. 예전에는 옮기면 배경이 사라졌어요.
- "윈도우 켤 때 같이 켜기"를 켜 둔 채 폴더를 옮겨도, 옮긴 곳에서 한 번 켜면 다음부터 거기서 자동으로 켜져요.
- 폴더를 옮긴 뒤 배경을 바꾸면 다른 칸 수 전용 그림이 지워질 수 있던 문제를 고쳤어요.

### 1.0.10 (11월 21일)

- 버튼 크기 고르기: 모든 버튼을 가로 1\~4칸, 세로 1\~2줄로 키울 수 있어요. 버튼 편집 창의 "크기"에서 고르거나, 패널에서 버튼 오른쪽 아래 모서리를 끌면 돼요. 자리를 비켜 준 버튼은 빈 칸으로 옮기고, 빈 칸이 모자라면 다른 페이지로 옮겨요.
- 패널 배경 그림: 설정 > 모양에서 그림 파일을 고르거나 화면을 캡처해서 패널 전체에 깔 수 있어요. 버튼은 그 위에 반투명하게 올라가고, "배경 위 버튼 진하기"로 얼마나 비칠지 정해요.
  - 캡처할 때 고르는 상자가 지금 패널 모양(가로:세로)으로 고정돼요.
  - 위치 맞추기: 패널에서 그림을 끌어서 옮기고 휠로 키우거나 줄여요. 가로 칸 수마다 구도를 따로 기억해요.
  - 가로 칸 수마다 다른 그림을 넣을 수도 있어요 (그 칸 수 전용 그림). 설정의 "맞출 칸 수"를 누르면 설정 창을 닫지 않고 패널이 그 칸 수로 바뀌어요.
  - 그림을 고르거나 캡처하면 바로 위치 맞추기가 시작돼요.
- 캐릭터 버튼 움직임이 많아졌어요 (메붕이 모드)
  - 가끔 하는 동작: 다른 걷기, 엎드려 쉬기, 둥실 날기, 경계 자세, 훈련하듯 공격 자세(휘두르기·찌르기·쏘기 등) 3\~4번 반복하기
  - 표정 15가지: 쉬다가 가끔 웃음·뽀뽀·사랑·더움, 누르면 불타오름, 주간 보스를 다 잡으면 빛남·반짝임·건배, 많이 남으면 우울·절망·울음·화남
  - 눈 깜빡임이 우는 얼굴로 보이던 것을 진짜 깜빡이는 얼굴로 바꿨어요.
  - 원래 있던 표정 일부가 바뀌었어요. 누를 때 표정은 당황 → 불타오름, 다 잡았을 때는 빛남·반짝임·건배, 많이 남았을 때는 우울·절망·울음·화남 중 하나예요.
  - 업데이트 후 처음 켜면 새 동작 그림을 받아요. 캐릭터 하나에 150장쯤(2\~3MB)이라 잠깐 걸려요.
- 설정 창·편집 창·업데이트 창을 열 때마다 창 아이콘이 하나씩 메모리에 남던 문제를 고쳤어요.

  - 내 넥슨 Open API 키로 캐릭터를 고르고, 누르면 이번 주 남은 주간 보스를 보여 줘요. 키는 이 PC에서만 풀리게 암호화해서 저장해요.
  - 캐릭터가 펫처럼 움직여요: 숨 쉬기·눈 깜빡임·걷기·다른 자세, 마우스를 올리면 윙크, 결과에 따라 표정이 바뀌고 다 잡으면 깡총 뛰어요.

  - 배경: 메이플 화면을 영역 캡처하거나 그림 파일을 골라서 깔고, 끌기·휠로 위치를 맞춰요. 발 높이 안내선에 맵 바닥을 맞추면 땅을 밟고 서 있어요.
